# ПР1. Ответы на контрольные вопросы

1. Python обнаружит ошибку только тогда, когда до неё дойдет ведь он интерпритируется в реальном времени. C# - язык компилируемый и компилятор изначально не пропустит базовые синтаксические ошибки.
2. Собирает проект (build) и запускает программу
3. bin - результат сборки а obj - промежуточные файлы сборки. они - не исходный код и хранить их в git нет необходимости
4. commit - создает коммит пока на локальном пк, push - пушит уже на гитхаб
5. `$""` - способ подставить значение переменной прямо в
   текст. а `+` это банальная арифметическая операция и с помощью неё конечно можно, но предпочтительнее всегда `$""`
6. результат округлиться. исправить это можно коммандой double хотя бы у одного значения.
7. const - неизменяемая перменная. например - число pi
8. нууу компилятор подставляет базовый синтаксис но у программиста остается возможно и самому написать любимый метод Main
